# RadianTech Corporate Website

Modern, responsive corporate website for **RadianTech** — built with Vite, React, and Tailwind CSS.

## Features

- Clean modern UI with glassmorphism, gradients, and smooth animations
- Fully responsive (mobile / tablet / desktop)
- Dark mode with persistent toggle
- React Router multi-page structure
- Component-based architecture
- SEO-friendly meta tags
- Accessible focus states & reduced-motion support

## Pages / Sections

| Route            | Content                          |
|------------------|----------------------------------|
| `/`              | Hero + About + Why Choose Us + Testimonials |
| `/services`      | Services                         |
| `/solutions`     | Industry Solutions               |
| `/portfolio`     | Portfolio / Case Studies         |
| `/technologies`  | Tech Stack                       |
| `/contact`       | Contact Form                     |

## Tech Stack

- **Vite 5**
- **React 18**
- **React Router DOM 7**
- **Tailwind CSS 3**
- **Lucide React** (icons)
- **clsx** + **tailwind-merge**

## Getting Started

```bash
# Install dependencies
npm install

# Start development server (http://localhost:5173)
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
